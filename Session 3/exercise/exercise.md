# The Oracle's Hidden Distribution

The Oracle has shed its bent lines and folded planes. It no longer speaks in ReLUs — now it speaks in means, spreads, and ratios. Perform the sequence of calculations below to reveal the unlock code.

## The Dataset

The Oracle offers you a small sample, drawn from an unknown population:

$$x = \{12,\ 15,\ 18,\ 9,\ 21,\ 15\}$$

$$n = 6$$

## Required Calculations

### 1. Sample Mean ($\bar{x}$)

$$\bar{x} = \frac{\sum x}{n}$$

### 2. Sample Variance ($s^2$) — with Bessel's Correction

$$s^2 = \frac{\sum (x - \bar{x})^2}{n - 1}$$

### 3. Sample Standard Deviation ($s$)

$$s = \sqrt{s^2}$$

### 4. Coefficient of Variation (CV)

$$\text{CV} = \left(\frac{s}{\bar{x}}\right) \times 100\%$$

### 5. Final Values

Compute $\bar{x}$, $s^2$, $s$, and CV using the steps above.

## Password Format

Write your computed $\bar{x}$, $s^2$, $s$, and CV values to exactly two decimal places, separated by commas and no spaces, no % sign (e.g., 1.00,2.00,3.00,4.00).
