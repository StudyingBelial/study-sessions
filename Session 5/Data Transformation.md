# Overview
Data Transformation is an intermediary step in the preprocessing pipeline, typically preformed before data warehousing, meant to standardize the data into an analysis read format. This is important not only in Machine Learning but for general data integration, where the most important thing is ensuring the data match the target, be it a certain format for the system or how the Machine Learning algorithm need its data to be processed.

## Use cases
1. Business Intelligence: Organizations need to process large amounts of data to make informed business decisions as such data transformation is crucial to get standard formatted data for proper processing.
2. Data Warehousing: Transformation is essential to structure the data for efficient and fast querying and analysis in a Data Warehouse or a Data Lake.
3. Machine Learning: ML algorithms require clean, organized and standardized data.
4. Big Data Analysis: Much like Business Intelligence or ML applications, there must be a clean and proper formatting of data for it to be processed at large amounts with low query processing overhead.
5. Data Migration: Simply, structured and formatted data is more efficiently processed and transferred instead of raw bulk transfers.

## Techniques Used in Machine Learning
Data Transformation in general IT and Computer Science differs from when referring to Data Transformation for Machine Learning purposes.
1. Standardization and Formatting
2. Deduplication
3. Aggregation and Binning
4. Filtering and Cleaning
